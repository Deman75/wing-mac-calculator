# Инструкции Codex для проекта WingMAC

## Задача

Поддерживать и развивать учебный калькулятор САХ крыла на HTML + CSS + JavaScript + SVG.
Вести беседу с пользователем на русском языке. Делать минимальные обоснованные изменения; не переписывать интерфейс без запроса.

## Перед редактированием

1. Прочитай `README.md`, `index.html`, `styles.css`, `geometry.js`, `app.js` и `CHECKS.md`.
2. Найди функции `sectionCalc`, `calc` в `geometry.js`, `drawSVG` в `app.js` и все преобразования координат.
3. Объясни, что планируешь изменить, если правка нетривиальна.
4. Сохраняй существующие возможности при любой переработке.

## Математика и ограничения

- Единицы ввода: **мм** и **градусы**. Площадь для вывода в м² = мм² / 1e6.
- Модель крыла симметрична; расчеты интегрируются по правому полукрылу, полная площадь удваивается.
- Внутренняя и внешняя секции линейно меняют хорду; стреловидность — угол **передней кромки** к перпендикуляру к оси самолёта (по полурамаху Y).
- Передняя кромка начинается в `(X=0, Y=0)`. Положительный X назад, Y к законцовке.
- САХ секции: `I2/I1`, где `I1=∫c(y)dy = S`, `I2=∫c(y)^2 dy`.
- Общее значение: `MAC_total = (S1*MAC1 + S2*MAC2)/(S1+S2)`.
- Для геометрической референсной линии используем площадь-взвешенные координаты передней кромки локальных САХ:
  `X_LE = (S1*X_LE1 + S2*X_LE2)/(S1+S2)`;
  `Y = (S1*Y1 + S2*Y2)/(S1+S2)`.
- Локальное положение САХ трапеции на центроиде площади:
  `y_local = b*(c0+2*c1)/(3*(c0+c1))`.
- ЦТ в процентах САХ: `X_CG = X_LE + MAC_total*p/100`.
- Не путать геометрическую центровку с аэродинамически рекомендованной/допустимой.
- Если `innerSpan=0`, **не** образуется нулевая секция со скачком хорды: консоль начинается с `rootChord`, поле `jointChord` игнорируется.
- Если `outerSpan=0`, нет внешней секции. Случай обе секции = 0 — ошибка ввода.
- Условия разбиения и крайние хорды проверять отдельно.
- Не использовать формулу `∫y*c² / ∫c²` для координаты геометрической САХ, принятой в этом проекте.
- Не подменять место общей САХ поиском локальной хорды той же длины: это неверно для составного крыла.

## Проверки перед сдачей изменений

1. Запустить синтаксическую проверку JS: `node scripts/check.cjs`.
2. Проверить численные сценарии из `CHECKS.md`, включая zero-span и разные стреловидности: `node --test tests/geometry.cjs tests/build.cjs`.
3. По возможности открыть страницу в браузере, проверить отсутствие JS-ошибок в консоли.
4. Проверить, что при изменении полей немедленно обновляются SVG, значения и маркер ЦТ.
5. Убедиться, что подписи не налезают друг на друга на экране 1440px и узком мобильном экране.
6. Не считать проверку синтаксиса заменой запуска браузера.
7. Если нет возможности проверить браузер, явно сообщить об этом, не утверждать, что всё протестировано.
8. После изменений собрать `node scripts/build.cjs` и проверить сайт и автономный `dist/wing-mac-calculator.html`. Генерируемый `dist/` не коммитить.

## UX / дизайн

- Приоритет — большая инженерная схема **правого полукрыла** с честным единым масштабом X и Y.
- Тонкая обводка крыла; контрастная общая САХ; пунктирные проекции начала/конца общей САХ до оси симметрии.
- Подписи не перекрывают линии и заголовки; избегай дублирования надписей и перенасыщенности.
- Показывать основные результаты сразу: `Y САХ`, `X_LE САХ`, `длина САХ`, `X ЦТ`.
- Второстепенные результаты и настройки — в сворачиваемых разделах `<details>`.
- Поля секций связаны: стыковочная хорда общая для обеих секций.
- Оси X/Y со стрелками и `(0,0)` на схеме; текстовые объяснения формулы отдельно.
- SVG предпочтительнее canvas; не использовать изображение вместо интерактивного чертежа.
- Не добавлять зависимости без явной необходимости.

## Рабочий процесс

- По возможности действуй прямо в проекте VS Code.
- Не генерируй новый HTML-файл с номером версии при каждом изменении: правь исходники `index.html`, `styles.css`, `geometry.js`, `app.js`, сохраняя git-историю. Автономный HTML создаётся только скриптом сборки.
- Для больших изменений сначала сделай небольшой отдельный коммит / предложи пользователю Git.
- Поясняй что поменялось, какие проверки выполнены и что осталось непроверенным.
