# WingMAC — интерактивный калькулятор САХ крыла

Учебный HTML/JavaScript/SVG-калькулятор средней аэродинамической хорды (САХ, MAC) симметричного крыла с **двумя трапециевидными секциями на полукрыле**.

[Открыть калькулятор](https://deman75.github.io/wing-mac-calculator/) · [Скачать автономный HTML](https://deman75.github.io/wing-mac-calculator/wing-mac-calculator.html)

## Начало работы

1. Откройте папку проекта в VS Code.
2. Для разработки откройте `index.html` в браузере вместе с соседними `styles.css`, `geometry.js` и `app.js`. Внешние библиотеки и установка зависимостей не нужны.
3. Для проверки опубликованной версии при установленном Node.js 24+: `node scripts/serve.cjs`, затем откройте `http://127.0.0.1:8080`. Сервер собирает сайт при запуске; после изменения исходников перезапустите его.
4. Для передачи одним файлом: `node scripts/build.cjs`. Готовый автономный файл — `dist/wing-mac-calculator.html`, его можно открыть без сервера и интернета.
5. Перед работой с Codex прочитайте `AGENTS.md` и `START_PROMPT.md`.

Готовые файлы вручную коммитить не нужно. Локальную сборку и проверки можно запускать также командами `npm run build` и `npm test`; на Windows при ограничении PowerShell используйте `npm.cmd` вместо `npm`.

## Текущая реализация

- Исходники разделены на HTML, CSS и JavaScript. Для обмена одним файлом используется автоматически собираемый `dist/wing-mac-calculator.html`; интернет для его работы не требуется.
- Две секции: внутренняя (от оси симметрии) и внешняя (консоль).
- Ввод: полуразмах каждой секции, корневая, стыковочная и концевая хорды, углы стреловидности **передней кромки** каждой секции.
- Связь: корневая хорда внешней секции автоматически равна конечной хорде внутренней.
- Если внутренний полуразмах равен 0, внешняя секция берет корневую хорду всего крыла, а стыковочная хорда игнорируется.
- Переключатель «Есть внутренняя секция (центроплан)» отключает её, задаёт нулевой размах и сворачивает раздел. При обратном включении раздел раскрывается и восстанавливается последний положительный размах.
- Поле начальной хорды внешней секции при наличии центроплана показывает конечную хорду внутренней секции и защищено от редактирования. Без центроплана оно становится доступным и задаёт корневую хорду всего крыла; поле в свёрнутом разделе внутренней секции синхронизируется с ним и недоступно для редактирования.
- Неиспользуемые хорды и углы не влияют на расчёт и чертёж. При нулевом внешнем размахе законцовкой становится конец внутренней секции; её хорда может быть нулевой.
- Пустой или некорректный ввод очищает все результаты. Углы используемых секций должны быть строго между −90° и 90°.
- Результаты: площадь, размах, удлинение, САХ секций, общая САХ, X и Y начала общей САХ, точка центровки в % САХ и мм от передней кромки корня.
- SVG: правое полукрыло, тонкий контур, геометрическое построение секций, общая САХ, пунктирные проекции, точка ЦТ, оси X/Y и раскрываемые панели.
- Размеры и результаты выводятся с двумя знаками после запятой; вычисления используют полную точность. При нажатии на числовое поле или переходе к нему клавишей Tab значение выделяется для замены.
- Мини-схема сборки общей САХ находится в отдельном раскрываемом блоке. На телефоне основной чертёж вписывается в экран с единым масштабом X/Y; кнопка «Увеличить» открывает подробный вид с горизонтальной прокруткой. Быстрые ссылки переключают между параметрами и результатом; поля и кнопки увеличены для нажатия пальцем.

## Система координат

- Начало геометрических координат `(X=0, Y=0)` — **передняя кромка корня крыла на оси симметрии**.
- `X` — по хорде **назад** (положительный X).
- `Y` — вдоль правого полукрыла от оси симметрии к законцовке (положительный Y).
- В SVG экранные координаты проецируются как `screenX = xOffset + scale * X`, `screenY = yOffset + scale * Y`.
- «Смещение назад X» означает продольную координату передней кромки общей САХ, не аэродинамический запас устойчивости.

## Принятая геометрическая модель

Для каждой секции с полуразмахом `b`, корневой хордой `c0`, концевой `c1`:
- площадь полукрыла секции `S = b*(c0+c1)/2`;
- `MAC = 2/3 * c0 * (1+λ+λ²)/(1+λ)`, `λ=c1/c0`, при `c0>0`;
- координата центра площади секции вдоль размаха (в локальной системе): `y_bar = b*(c0+2*c1)/(3*(c0+c1))`;
- при постоянной стреловидности ПЕРЕДНЕЙ кромки `Λ`: `xLE_bar = xLE_root + y_bar*tan(Λ)`.

Для двух секций:
- `MAC_total = (S1*MAC1 + S2*MAC2)/(S1+S2)`;
- `Y_total = (S1*Y1 + S2*Y2)/(S1+S2)`;
- `X_LE_total = (S1*X_LE1 + S2*X_LE2)/(S1+S2)`;
- заданная продольная координата ЦТ: `X_CG = X_LE_total + (p/100)*MAC_total`.

**Интерпретация:** САХ составного крыла — эквивалентная геометрическая хорда; ее общая линия **не обязана лежать на физической хорде крыла**. Для одной трапеции общая САХ обязана точно совпасть с САХ этой трапеции. Центровка в % САХ — только геометрическое задание координаты ЦТ, не рекомендация по устойчивости.

## Важно проверить/улучшить

- Геометрия и формулы рассчитаны для **плоской проекции симметричного крыла**, без крутки, скруглений законцовок, фюзеляжных вырезов и учета распределения аэродинамической нагрузки.
- Разные углы стреловидности требуют проверки граничных случаев: 0/отрицательный угол, нулевая длина одной секции, постоянная хорда, нулевая концевая хорда.
- SVG-подписи могут перекрываться при нетипичных соотношениях размеров; нужна проверка в браузере.
- Работающее поведение браузера проверяйте отдельно; простой `node --check` подтверждает только синтаксис JavaScript.
- Не меняйте формулы «ради красивой картинки»; сначала добавьте численный регрессионный тест.

## История важных решений

1. Canvas заменён SVG, поскольку для чертежа нужны точные пропорции, отдельные объекты и подписи.
2. Переход с прямоугольного центроплана на две произвольные трапециевидные секции.
3. Исправлена ошибка нулевого размаха внутренней секции: расчет и контур обязаны использовать одну эффективную корневую хорду.
4. Исправлено размещение общей САХ: вместо попытки найти место с такой же местной хордой — площадь-взвешенные координаты САХ секций.
5. Ввод центровки в процентах САХ и вывод X-координаты ЦТ.
6. Результаты сделаны компактными, с раскрываемыми дополнительными данными.
7. На SVG добавлены стрелочные оси X/Y и объяснение формул.

## Ожидаемое развитие

Сохранять простые раздельные исходники и автоматическую сборку одного автономного HTML для обмена. Не добавлять внешние библиотеки без необходимости. Ориентир — учебный сайт, понятный начинающему авиаконструктору, с точной геометрией.

## Автоматические проверки

При установленном Node.js 24+:

```text
node scripts/check.cjs
node --test tests/geometry.cjs tests/build.cjs
node scripts/build.cjs
```

Проверки запускают настоящий код из `geometry.js` и `app.js`: контрольные сценарии, независимое численное интегрирование, отсутствующие секции, валидацию, переключатель и согласованность SVG с расчётом. Тест сборки проверяет отсутствие внешних ресурсов в автономном HTML и совпадение расчётов, SVG и связей полей с исходной версией. Node.js и тесты нужны только для разработки; пользователю страницы они не требуются. Размещение подписей и поведение элементов проверяются отдельно в браузере.
